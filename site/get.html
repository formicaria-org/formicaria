Get it

Download the archive for your system from the latest release, unpack it, and double-click the launcher. Your browser opens by itself.

  • Linux

    Unpack the linux-x86_64 archive and double-click Start formicaria.sh.

    64-bit x86, glibc 2.34 or later (Ubuntu 22.04+, Debian 12+, Fedora 35+).

    • Download for Linux
    • Setting up on Linux

  • macOS

    Unpack the macos-arm64 archive and double-click Start formicaria.command.

    Apple silicon. The first time, macOS warns about unsigned software: System Settings → Privacy & Security → Open Anyway.

    • Download for macOS
    • Setting up on macOS

  • Windows

    Unpack the windows-x86_64 zip and double-click Start formicaria.vbs.

    Windows 10 or 11, 64-bit. The setting-up chapter says what to do about the security warning.

    • Download for Windows
    • Setting up on Windows

  • Android and iPhone

    The same release carries an Android .apk and an iPhone .ipa. Both need a little more than a double-click, and each has its own chapter.

    The iPhone chapter is not optional reading: Apple's free signing expires after seven days.

    • On an Android phone
    • On an iPhone

All you need besides is a current web browser — Firefox, Chrome, Safari or Edge. Closing the tab stops the app about a minute and a half later, unless a reminder is waiting. Later versions are installed from inside the app: Settings, Check now. Each archive also carries the whole manual, to read offline.
