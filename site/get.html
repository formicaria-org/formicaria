Get it

Pick your device. One button downloads it; a few taps or a double-click start it. No account, nothing to sign up for.

On an Android phone or tablet

Download for Android

  1. Open this page on the phone and tap the button above. If the browser asks whether to keep the file, tap Download.
  2. When it has downloaded, tap Open.
  3. Android says it cannot install apps from this source, because the app is not from the Play Store. Tap Settings, switch on Allow from this source, and go back.
  4. Tap Install, then Open. Done.

If the phone shows one more screen — a virus check, or "Play Protect" — choose Install anyway (sometimes under More details). It does this for any app from outside its store. You only install once: after that the app tells you about new versions itself. More about Android.

On a computer

  • Windows

    Download for Windows

    Right-click the downloaded file, choose Extract All, then open the new folder and double-click Start formicaria. Your browser opens: that is the app.

    Windows 10 or 11, 64-bit. Windows warns about an app it does not know — what to click.

  • Mac

    Download for Mac

    Double-click the downloaded file to unpack it, then open the new folder and double-click Start formicaria. Your browser opens: that is the app.

    Macs with Apple silicon (2020 or later). The first time, macOS refuses an app it does not know: System Settings → Privacy & Security → Open Anyway. Step by step.

  • Linux

    Download for Linux

    Unpack it, open the new folder and double-click Start formicaria. Your browser opens: that is the app.

    64-bit, Ubuntu 22.04, Debian 12, Fedora 35 or newer. Step by step.

Unpack before you start it — never run it from inside the zip, where Windows would later delete your notes with the temporary folder. Closing the browser tab stops the app; double-clicking Start formicaria starts it again. New versions install from inside the app.

On an iPhone or iPad

Not simple yet, and we would rather say so. Apple only lets an app outside the App Store onto an iPhone if you sign it with your own Apple ID, using a computer and a free tool — and that signature runs out after seven days. The iPhone chapter walks through it.

Looking for something else — an older version, or the files for checking a download? They are all on the release page, which is made for developers.
