# Start here

This is your notebook. Each note is a plain file in the **vault** folder beside the app.

- **Write:** press **+**, then **New note**. To change a note, click or tap its text.
- **Find it:** the list of views shows the same notes in different ways — **Timeline**,
  **Board**, **Agenda** — and **Search** finds any word.
- **Keep it safe:** **Back up**.
- **Lost?** **Home**, first in the list of views, shows all of this with pictures. **Help** and
  **Settings** are at the end of the same list.

You can delete this note whenever you like. Nothing depends on it.
