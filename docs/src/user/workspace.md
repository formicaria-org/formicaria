# Layout and the keyboard

How the app arranges what you have open, and the keys that move around it. All of this is a
preference **of this device** — nothing here changes your notes or travels with them.

## One view or several

**Settings → Look → Layout** has two answers:

- **One view** — the default, on every device. You see one thing at a time: a view, or the note you
  opened from it. The strip of buttons (along the side of a wide window, or behind **Views** on a
  narrow one) moves between them, and **Back** returns to where you were.
- **Tiled** — several views side by side in a grid, each with its own header you can drag to
  rearrange. Useful on a large screen when you want a board and a note open together.

A note is always a window of its own: it closes with **×** in its header, and the view you opened it
from is still there behind it.

## Columns

Only for **Tiled**. **Settings → Look → Columns** sets how wide the grid is. **Automatic** follows the
number of open views — opening one widens the grid, closing one lets the others take the room back. A
number pins the grid at that many columns, however many views are open.

## Keyboard shortcuts

**Settings → Keyboard** lists every shortcut and lets you change it: click the shortcut, then press
the keys you want (**Esc** cancels). A shortcut already in use says so, and so does one the browser
would take before the app sees it. **Reset to defaults** puts them all back.

| Action | Key | Works while typing in a note? |
|---|---|---|
| Settings and the actions list | Ctrl+K (⌘K on a Mac) | yes |
| Next view | Ctrl+. | yes |
| Previous view | Ctrl+, | yes |
| New note | C | no |
| Search | / | no |
| Undo | Ctrl+Z | no — inside a note it undoes your typing |
| Redo | Ctrl+Shift+Z | no |
| New view, Close this view, Back up | not set | — set one if you want it |
| Bold, in a note | Ctrl+B | only there |
| Italic, in a note | Ctrl+I | only there |
| Code, in a note | Ctrl+E | only there |
| Highlight, in a note | Ctrl+Shift+H | only there |

The four *in a note* keys format the words you are writing, and do nothing elsewhere. Each needs
Ctrl or Alt, since a bare letter would type itself instead; Settings says so if you try.

*Next view* and *Previous view* work even while you are writing, which is why they exist: without
them a note had to be closed before anything else could be reached.

On a phone or tablet there is no keyboard to speak of: the same actions are in **Settings → Do
something**.
