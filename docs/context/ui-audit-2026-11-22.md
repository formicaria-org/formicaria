# The first hour — an interface audit against the mainstream (2026-11-22)

**Asked by the owner:** *"I think we really need to bring our current UI closer to user demands, but
are we so far?"*, then *"do the audit first then settings plan"*.

**Method.**
- The 20 things a new person does in their first hour, each compared with how **Notion** and
  **Obsidian** do it.
- Each one measured in **formicaria's own browser** on a computer (1440 × 900, headless, an
  invented vault), the way a person uses it:
  - pictures of every screen;
  - the controls a person can see, listed;
  - each conventional path tried with real key presses and clicks.
- The harness is `ci/usability-check.py`, persona `audit` (`first_hour_pictures`,
  `first_hour_walk`), run on request: `FM_USABILITY_ONLY=audit pixi run usability-check`. It
  writes `audit-*.png`, `audit-*.json` and `audit-walk.json` to the check's work folder.
- A gap is a finding, not a failed release. A gap fixed becomes an ordinary check.
- **Phone tasks were not walked** (rows marked *code*): they are read off the code, and the phone
  pass is a later run in the emulator.

## The headline

**The computer lost several basics when it moved to the one frame** (`decisions.md` 2026-11-17).
formicaria's browser shows feature pages (`ui/src/feature/Feature.svelte`). Search, the command
palette, the undo menu and *Recently deleted* live only in the older frame (`ui/src/App.svelte`),
which a computer no longer shows. Measured, on a computer:
- **no way to search your notes**: no field on any screen, and **/** opens Firefox's own
  page-find bar;
- **Ctrl+K opens nothing** (the Settings page is even handed an empty command list);
- **deleting a note offers no Undo, Ctrl+Z does not bring it back, and *Recently deleted* cannot be
  reached.**

These are regressions, not missing features: the code exists, and the new frame does not mount it.

## What to do, in order

**U1 — bring back what the computer lost, and fix what is broken (no ruling needed).** *Done
2026-11-22, for 0.60.8: rows 3, 4, 9, 10 and 11 now ✅, plus S1, S2 and S5. S5 turned out to be the fade
mask, not the line clamp (`audit-01b-no-mask`). Checked by the persona* someone in their first hour.
1. **Search on every feature page**: a field in the header (*Search notes*), plus **Ctrl+K** for
   the palette (notes by name, then commands). Both exist in `App.svelte`: mount them in
   `Feature.svelte`, and take **/** back from Firefox's find bar when the page has the focus.
2. **Undo**:
   - a toast with *Undo* after every delete;
   - Ctrl+Z for the last action outside the text;
   - *Recently deleted* reachable from the Notes page's menu and from Settings → Vaults & backup.
3. S1 (Escape and clicking outside close menus), S2 (tab titles), S5 (previews).

Each of these gets a usability check: the walk's row turned into an assertion.

**U2 — conventions, each needing the owner's yes (decision entries).**
1. **⋯ for a note's options**, ＋ only ever *adds* (S4).
2. **`[[` opens the same note finder as `/`**: Obsidian users type it without thinking.
3. **"vault" shown only when there is more than one** (S3).
4. **Import at the top level**: Settings → *Import* (a section of its own), and *Bring your notes:
   Obsidian, Logseq* on the welcome screen.
5. **Export**: ⋯ → *Export* as Markdown, PDF, or HTML.
6. **History**: ⋯ → *History*, the note's file through git, with *Restore this version*.
7. The note page shows its tags and date, and a visible editing affordance (S6).

**U3 — features behind standing rulings (owner).**
1. **Make your own view** (table, board, cards from properties): reverses "no view authoring".
2. Two notes side by side on a computer.

**Effect on the Settings plan** (`settings-plan-2026-11-21.md`, next):
- Import becomes a Settings category of its own (U2.4).
- *Recently deleted* sits in Vaults & backup (U1.2).
- Settings stops being a card with its own × inside a tab (S7).
- Keyboard lists the palette's shortcut (U1.1).
